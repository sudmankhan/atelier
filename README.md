# FORM & GRAIN

An interactive woodworking and chairmaking studio for studying furniture, exploring
geometry in 3D, producing shop outputs, matching lumber to parts, and learning from
an AI mentor grounded in the project's curated knowledge library.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

Mentor chat and lumber inspection require a server-side `GEMINI_API_KEY`.
Voice narration optionally uses `ELEVENLABS_API_KEY`.
